# AI-Tools（MCP Dock）软件介绍

> 一款面向 AI 编程客户端的桌面应用，统一管理 MCP Server 与 Agent Skills 的配置，让开发者告别手动编辑 JSON、跨客户端同步的繁琐。

---

## 一、这是什么

**AI-Tools（产品名 MCP Dock）** 是基于 Electron 的跨平台桌面工具，用于集中管理各类 AI 编程客户端（Cursor、VS Code、Claude Code、Gemini CLI、Codex CLI、Trae、JetBrains 等）的 MCP Server 与 Agent Skills 配置。

在 AI 编程工具爆发式增长的今天，每个客户端都有自己的配置文件格式与存放路径。手动维护这些配置既容易出错，又难以在多工具间保持一致。AI-Tools 将这些配置收拢到一个界面中，提供浏览、安装、调试、备份与同步的一站式体验。

- **当前版本**：1.0.0
- **支持平台**：Windows / macOS / Linux
- **开源协议**：MIT（源码）/ 专有（安装包）
- **项目主页**：<https://github.com/OldJii/mcp-dock>

## 二、核心功能

### 1. MCP 商店
内置来自 **Official Registry** 与 **Smithery** 两个数据源的 8500+ 个 MCP Server，支持关键词搜索、分类筛选与详情查看。数据每 3 天自动同步一次。

### 2. Skills 商店
发现 4400+ 个 AI Skills（Agent 技能），覆盖 Cursor、Claude Code、Gemini CLI、Codex CLI、Opencode 等客户端，并兼容 `~/.agents/skills/` 统一标准（[skills.sh](https://skills.sh/)）。

### 3. 一键安装
选中一个 MCP Server 或 Skill，即可自动写入对应客户端的配置文件，无需手动复制粘贴 JSON。支持同时安装到多个客户端。

### 4. MCP Inspector
内置交互式调试器，通过 MCP JSON-RPC 协议直接调用 Server 暴露的 Tools，在图形界面中测试输入与返回结果，快速验证配置是否正确。

### 5. 配置管理与多端同步
统一管理所有客户端的 MCP 配置；可将同一份配置一键同步到多个客户端，保证工具链行为一致。

### 6. 云端同步
支持将 MCP 与 Skills 配置推送到云端存储（Cloud），实现备份与跨设备同步，换机或重装后一键恢复。

### 7. 历史记录与回滚
每次修改配置自动备份，出现问题时可一键回滚到任意历史版本，避免误改导致客户端无法启动。

### 8. 多语言界面
完整支持简体中文与英文界面，跟随系统或手动切换。

## 三、支持的客户端

AI-Tools 当前支持 **19 个 MCP 客户端** 与 **11 个 Skills 客户端**：

**MCP 客户端**
Cursor、VS Code、Claude Code、Gemini CLI、Codex CLI、Windsurf、Zed、TRAE、TRAE CN、TRAE 插件（MarsCode）、Kiro、Opencode、JetBrains（IntelliJ / WebStorm / PyCharm 等）、Antigravity、OpenClaw、CodeBuddy、WorkBuddy、Qoder、云端存储（Cloud）。

**Skills 客户端**
Cursor、Claude Code、Gemini CLI、Codex CLI、Opencode、Agent Skills（`.agents`）、CodeBuddy、WorkBuddy、Qoder、TRAE 插件（MarsCode）、云端存储（Cloud）。

> 客户端安装状态会被自动检测，界面仅展示本机已安装的客户端，也可在设置中自定义配置路径。

## 四、适合谁用

- **日常使用多个 AI 编程工具的开发者**：希望 MCP 配置在各工具间保持一致。
- **MCP Server / Skill 作者**：需要频繁调试、验证自己的配置在各客户端是否生效。
- **团队 / 企业**：通过云端同步统一分发团队共用的 MCP 与 Skill 配置。
- **开源贡献者**：可通过社区注册表提交自己的 Server / Skill 配置。

## 五、快速上手

1. 从 [Releases](https://github.com/OldJii/mcp-dock/releases) 下载对应平台安装包并安装。
2. 打开应用，左侧「MCP 商店」浏览或搜索需要的 Server。
3. 点击「安装」，选择目标客户端（如 Cursor、VS Code）。
4. 到对应客户端中即可直接使用该 MCP 能力。
5. 配置有误时，进入「历史」页一键回滚；多设备用户可在「设置」中配置云端同步。

所有配置与数据均存储在本地（macOS / Linux：`~/.ai-tool/`，Windows：`%USERPROFILE%\.ai-tool\`），首次加载商店列表需联网，已安装配置离线可用。

## 六、技术亮点

- **三层进程架构**：主进程（配置读写 / IPC）、预加载（安全桥接）、渲染进程（React 界面），职责清晰。
- **19 客户端适配层**：`config-manager` 统一抽象各客户端的路径、格式（如 VS Code 使用 `servers` 键而非 `mcpServers`）与安装检测。
- **云端同步服务**：通过 `cloud-sync-service` 实现配置加密推送 / 拉取。
- **可扩展数据源**：Registry API 层支持 Official 与 Smithery 双源，社区可通过 JSON Schema 提交新条目。

**技术栈**：Electron 43 · React 18 · TypeScript 5.3 · Tailwind CSS 3.4 · Zustand 4 · Vite 7 · electron-builder 24 · Vitest 4。
